# Coding guidelines

These instructions apply to this workspace and its subdirectories.

Before writing, reviewing, or refactoring code, read and apply
`.agents/skills/karpathy-guidelines/SKILL.md` relative to this workspace root.
This is the project-local copy of the skill from
https://github.com/multica-ai/andrej-karpathy-skills.

Apply its four principles:

1. **Think before coding:** make assumptions explicit, identify material ambiguity,
   and explain relevant tradeoffs before implementing.
2. **Simplicity first:** implement the minimum needed for the requested outcome;
   avoid speculative features and unnecessary abstractions.
3. **Surgical changes:** keep changes within the requested scope, follow existing
   style, and clean up unused code introduced by your own changes.
4. **Goal-driven execution:** define observable success criteria, use appropriate
   checks, and report verification results and any remaining limitations.

Use judgment for trivial changes; scale planning and verification to the task.
